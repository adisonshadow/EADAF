# 三员审批与审计

三员用于涉密 / 等保里的职责分离。开关在 **设置 → 通用 → 系统 → 是否启用三员管理**。

关闭时，菜单、授权和下面这些操作都与未启用时相同，立即执行。开启后才出现「三员」菜单，高风险操作改为先审批。

## 1. 三类身份

一个人最多一种身份，也可以不填（普通用户）。同类可以有多人。

| 身份 | 主要能做的事 |
| --- | --- |
| 系统管理员 | 维护成员与部门、备份、日志滚动，并可操作权限管理、应用列表，以及业务数据里的数据库连接。停用 / 归档 / 删除用户、重置密码、恢复数据库、改日志滚动要等审批 |
| 安全保密管理员 | 管角色、菜单 / 按钮权限、用户的三员属性。在「三员 → 审批」里批准或驳回 |
| 安全审计员 | 看系统日志、系统健康，并在「三员 → 三员审计」里核查前两类人的操作 |
| 普通用户（属性为空） | 按原有角色使用业务菜单。三员账号看不到业务菜单；系统管理员例外，只能进业务数据里的数据库连接 |

开启时必须指定三名不同的在职用户，各任一类。请把当前账号放进其中一类，否则开启后进不了管理功能。

关闭三员、修改三员属性、修改菜单 / 按钮的三员性质，由安全保密管理员直接保存，不进审批队列。这些操作会记入操作日志，审计员事后可以查到。安全保密管理员不能批准自己提交的申请。

## 2. 安全保密管理员：审批

左侧菜单 **三员 → 审批**（仅该身份可见）。

系统管理员发起下列操作时，页面提示「已提交审批」，操作尚未执行：

- 恢复数据库
- 修改日志滚动（单个文件大小、保留天数、是否压缩）
- 停用、归档或删除用户
- 重置用户密码

审批页列出待办。批准后服务端才执行；驳回则不执行。可以填写一句意见。批准和驳回都会写入操作日志。

## 3. 安全审计员：核查与导出

左侧菜单 **三员 → 三员审计**。头像菜单里的「系统日志」「系统健康」也只给审计员。

审计页只列出**当时身份**为系统管理员或安全保密管理员的操作（写入日志时记下，之后改身份不会改历史）。可用操作类型筛选（创建、更新、删除、重置密码、执行等），也可按模块看。

用法：

1. 勾选 1 到 n 条日志，点「加入暂存」。
2. 暂存区和「安全风险评语」保存在本浏览器（按当前登录用户分开），刷新页面还在。
3. 点「导出 PDF」。浏览器会打开打印窗口，选择「存储为 PDF」。报告包含评语、导出时间和所选日志的时间、身份、操作者、类型、模块、资源。

暂存可以单条移除，或「清空暂存」（评语保留）。这是浏览器本地数据，换浏览器或清站点数据会丢失，不会写进服务器。
