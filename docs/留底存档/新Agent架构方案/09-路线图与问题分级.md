## 3. 重点修改点（文件级索引）

### MS0

| 改什么 | 路径（示意） |
|--------|----------------|
| `validateToolArgs` | `ai-base/src/utils/validateToolArgs.ts` |
| parse/validate 接入 | `useAIBaseChat.ts` / `functionRegistry` / 后端 `toolInvoke` |
| `display` 字段 + 默认推断 | `toolResponse.ts` / `normalizeToolResult.ts` |
| Surface 渲染 | `ToolInvokeSteps.tsx` 或新组件 |

### MS1

| 改什么 | 路径 |
|--------|------|
| Cordis boot | `ai-base` 新目录 `runtime/` 或 `cordis/` |
| Registrar → host pack | `frontend/src/components/AIChatClientToolsRegistrar`、各 `register*Tools.ts` |
| Provider 生命周期 | `AIChatProvider.tsx` |

### MS2

| 改什么 | 路径 |
|--------|------|
| 目录/正文 API | `aiCapabilityController` / `skillController` |
| `skill` harness | `builtinTools.ts` |
| prompt 组装 | `skillLoader.ts` |
| 路由截断 | `semanticRoutesToMarkdown.ts` |

见 [04](./04-代码运行时.md)、[08](./08-多应用扩展.md)、[06](./06-闭环与终止.md)。
