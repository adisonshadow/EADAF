# 实测1 手工验收清单

复测提示词：

> 帮我在 web 域下添加 Tag 和用户画像（Tag）的实体，只和 web 域有关系，然后创建 API

期望：

1. 首帧出现「正在准备 Skill 与工具…」，随后被 Tool 步骤替换（非直接空白跳到 update_plan）
2. `update_plan` ThoughtChain 标题为「生成任务清单 · N项」，结果区为步骤列表而非原始 JSON
3. `skill` 标题为「加载 Skill · {slug}」，结果为「名称（slug）」
4. Planning next moves 在 `update_plan` 后短暂出现；第一条业务 Tool（如 list）开始后消失
5. **不出现** `http_request` → `/api/v1/bizdata/...` 404；应走 `bizdata_list_entity_summaries` / `bizdata_list_enums` / `bizdata_entity`
6. 若误调 `http_request`：结果默认折叠，下一条 Tool 开始后保持折叠（transient）
7. `run_code` 若探测 tools，`Object.keys(tools)` / `tools.list()` 非空

库侧（可选）：

```bash
psql "$DATABASE_URL" -f backend/scripts/migrate-bizdata-entity-tool-and-http-guard.sql
psql "$DATABASE_URL" -f backend/scripts/migrate-api-request-log-tool-audit.sql
```
