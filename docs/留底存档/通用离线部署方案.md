# 二、CentOS8 离线安装静态Docker完整操作文档（现场人员执行）

> 
> 前提：已经把 `centos-docker-static` 目录拷贝进离线CentOS8服务器
> 宿主机全程**无外网、不dnf/yum安装任何依赖、不编译**

## 2.1 目录进入与脚本准备

```
# 进入目录
cd centos-docker-static
# 添加脚本执行权限
chmod +x install-docker-static.sh
```

## 2.2 install-docker-static.sh 完整内容

```
#!/bin/bash
set -e
echo "===== CentOS8 x86_64 离线安装静态Docker 24.0.9 ====="

# 解压docker静态二进制包
echo "1. 解压docker静态包"
rm -rf docker
tar -zxvf docker-24.0.9.tgz

# 复制docker二进制到系统PATH
echo "2. 拷贝docker程序到 /usr/local/bin"
cp docker/* /usr/local/bin/
chmod +x /usr/local/bin/docker*

# 安装docker compose v2
echo "3. 安装 docker-compose"
cp ./docker-compose /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose
# 创建软链接，支持 docker compose（空格命令，适配compose yaml）
ln -sf /usr/local/bin/docker-compose /usr/local/bin/docker-compose-v2

# 编写systemd docker服务单元
echo "4. 写入docker systemd服务"
cat > /etc/systemd/system/docker.service <<EOF
[Unit]
Description=Docker Application Container Engine
Documentation=[https://docs.docker.com](https://docs.docker.com)
After=network-online.target firewalld.service
Wants=network-online.target

[Service]
Type=notify
# 静态dockerd路径
ExecStart=/usr/local/bin/dockerd
ExecReload=/bin/kill -s HUP \$MAINPID
TimeoutSec=0
RestartSec=2
Restart=always
# 允许iptables
LimitNOFILE=infinity
LimitNPROC=infinity
LimitCORE=infinity

[Install]
WantedBy=multi-user.target
EOF

# 重载systemd，设置开机自启并启动docker
echo "5. 启动Docker并设置开机自启"
systemctl daemon-reload
systemctl enable docker
systemctl start docker

# 验证安装
echo ""
echo "===== 验证结果 ====="
docker --version
docker-compose --version
echo "Docker安装完成！"
```

## 2.3 执行安装

```
./install-docker-static.sh
```

## 2.4 验证

```
# 查看docker信息
docker info
# 测试compose
docker-compose version
```

## 2.5 卸载（备用，现场回滚使用）

```
systemctl stop docker
systemctl disable docker
rm -f /etc/systemd/system/docker.service
rm -f /usr/local/bin/docker*
systemctl daemon-reload
```

## 2.6 重要说明

1. 静态Docker不修改系统rpm数据库，不会新增系统软件包
2. 不需要联网，全部预编译二进制，现场**无任何编译操作**
3. 内核要求：CentOS8内核 ≥4.18，`uname -r` 检查
4. 如需放行端口：firewalld示例（按需）

```
# 开放80、3000端口
firewall-cmd --add-port=80/tcp --permanent
firewall-cmd --add-port=3000/tcp --permanent
firewall-cmd --reload
```

# 三、【给AI编码工具使用的构建打包文档】

> 
> 角色：本地AI编码工具，在Mac电脑执行所有构建任务
> 目标：
> 
> 
> 1. 前端项目执行build生成dist静态资源
> 2. 构建BFF Node服务的docker镜像（linux/amd64）
> 3. 拉取所有基础镜像（linux/amd64）
> 4. 导出全部镜像为tar包
> 5. 生成完整离线deploy目录，打包压缩，**所有产物不包含前端node_modules；BFF依赖全部内置到docker镜像，不拷贝Mac本地node_modules**
> 约束：**所有镜像架构必须 linux/amd64，适配离线CentOS8 x86_64服务器**

## 前置信息

- 本地机器：Mac（M系列或Intel），Docker Desktop已安装并正常运行
- 目标服务器：CentOS8 x86_64（amd64）完全离线
- 项目结构：

```
project-root/
├── frontend/          # 前端项目
├── bff/               # BFF Node后端项目
├── nginx/conf/        # nginx站点配置
├── init-sql/          # 数据库初始化sql脚本
├── docker-compose.yml
├── .env
```

## 任务1：前端构建（frontend）

1. 进入frontend目录
2. 执行 `npm install`（仅本地打包使用）
3. 执行生产打包命令 `npm run build`
4. 打包产物输出至 `frontend/dist`
5. **打包完成，删除frontend/node_modules，不要放进离线部署包**> 
> 前端dist为纯静态资源，后续挂载到nginx容器

## 任务2：准备BFF项目文件

bff目录内创建2个文件：

### bff/Dockerfile

```
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
CMD ["node", "server.js"]
```

### bff/.dockerignore

```
node_modules
.DS_Store
.env
npm-debug.log
*.log
```

## 任务3：初始化Docker buildx（M芯片Mac必须执行；Intel Mac可跳过）

```
# 只执行一次
docker buildx create --name x64builder --use || true
docker buildx inspect --bootstrap
```

## 任务4：拉取所有基础镜像，强制架构 linux/amd64

> 
> 所有镜像必须指定 `--platform linux/amd64`

```
docker pull --platform linux/amd64 node:20-alpine
docker pull --platform linux/amd64 nginx:1.25-alpine
docker pull --platform linux/amd64 postgres:15-alpine
docker pull --platform linux/amd64 mysql:8.0
docker pull --platform linux/amd64 redis:7-alpine
```

## 任务5：构建BFF镜像（linux/amd64）

进入bff目录执行：

```
# M Mac使用buildx
docker buildx build --platform linux/amd64 -t bff:v1 . --load

# Intel Mac直接build（可选，如buildx不存在）
# docker build --platform linux/amd64 -t bff:v1 .
```

> 
> 标签：`bff:v1`

## 任务6：导出全部镜像tar包

在project-root根目录，创建脚本 `save-images.sh`

```
#!/bin/bash
# 清理Mac隐藏文件
find . -name ".DS_Store" -delete

# 镜像清单
IMAGES=(
"node:20-alpine"
"nginx:1.25-alpine"
"postgres:15-alpine"
"mysql:8.0"
"redis:7-alpine"
"bff:v1"
)

mkdir -p ./eadaf-runtime/docker-images

for img in "${IMAGES[@]}"; do
  filename=$(echo "$img" | tr ':' '_').tar
  echo "正在导出镜像 $img -> ./eadaf-runtime/docker-images/$filename"
  docker save -o "./eadaf-runtime/docker-images/$filename" "$img"
done

echo "所有镜像导出完成"
```

```
chmod +x save-images.sh
./save-images.sh
```

## 任务8：打包压缩离线包

```
# 清理DS_Store垃圾文件
find ./eadaf-runtime -name ".DS_Store" -delete
# 打包
tar -zcvf eadaf-runtime-v1.0.tar.gz eadaf-runtime
```

## 任务9：离线服务器加载镜像&启动服务

```
# 解压
tar -zxvf eadaf-runtime-v1.0.tar.gz
cd eadaf-runtime

# 加载全部镜像
for f in ./docker-images/*.tar; do docker load -i "$f"; done

# 检查镜像列表，确认全部为amd64架构
docker images

# 修改 .env 里面数据库账号密码、业务配置

# 启动整套服务
docker-compose up -d

# 查看日志
docker-compose logs -f
```

## docker-compose.yml 完整文件

```
version: '3.8'
services:
  nginx:
    image: nginx:1.25-alpine
    ports:
      - "80:80"
    volumes:
      - ./frontend/dist:/usr/share/nginx/html
      - ./nginx/conf:/etc/nginx/conf.d
    depends_on:
      - bff
  bff:
    image: bff:v1
    ports:
      - "3000:3000"
    depends_on:
      - postgres
      - mysql
      - redis
    env_file: .env
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_USER: ${PG_USER}
      POSTGRES_PASSWORD: ${PG_PASSWORD}
      POSTGRES_DB: ${PG_DB}
    volumes:
      - pgdata:/var/lib/postgresql/data
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DB}
    volumes:
      - mysqldata:/var/lib/mysql
  redis:
    image: redis:7-alpine
    volumes:
      - redisdata:/data
volumes:
  pgdata:
  mysqldata:
  redisdata:
```
