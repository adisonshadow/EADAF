# 数据包导出 / 导入（应用部署）

管理端导航 **应用部署** 下提供两类 ZIP 数据包，用于在两套已运行的 EADAF 实例之间迁移配置与数据：

- **应用部署 → 应用数据导出/导入**（`/app_deployment/app-data`）
- **应用部署 → EADAF数据导出/导入**（`/app_deployment/platform-data`）

这两项原先在「系统设置」里，现已迁到「应用部署」；设置页不再展示。与开发机打出的运行时安装包（`pnpm pack:eadaf` / `pnpm pack:app`，见 [pack-and-deploy.md](./pack-and-deploy.md)）不是同一类产物，文件名与入口都不同，不要混用。同组的「发布平台」「发布应用」只在 DEV 模式下可用。

运行时包里的~~数据包补丁~~已暂时停用。升级包、补丁包只有程序；表结构只在 EADAF 安装包的 init-db 里。除首次安装建表外，配置与业务数据都走本页。

| 类型 | 应用部署菜单项 | 典型文件名 | 用途 |
|------|------------|------------|------|
| 平台包 | EADAF数据导出/导入 | `eadaf-platform-export-*.zip` | 同步平台能力（Skill、AI 目录、数据标准等） |
| 应用包 | 应用数据导出/导入 | `eadaf-app-export-<应用编码>-*.zip` | 按业务应用迁移模型、API、行数据等 |

入口：登录管理端 → 左侧 **应用部署** → 对应菜单项。

> 导出文件可能含 **明文密钥**（应用接入密钥、Webhook / Provider API Key 等），请按涉密文件保管，勿提交到仓库或公开渠道。

---

## 1. EADAF 平台包

用于把 **本实例的平台能力** 同步到另一套 EADAF。不含业务应用、实体、业务 API 或物化行数据。

### 1.1 导出内容

- EADAF 全局 Skill，以及绑在 EADAF 上的专用 Skill / Tool / Scope
- 实例级 AI 目录（Provider / 模型 / 能力 / IO 标签；API Key 以明文段携带）
- 数据标准目录（`bizdata.data_standards`）
- 系统功能开关（`system_features`）
- UAC 权限目录（权限码；不含用户 / 部门 / 角色授权）
- 可选：EADAF / 系统存储桶及对象文件（不含业务应用桶）

### 1.2 操作步骤

1. 打开 **应用部署 → EADAF数据导出/导入**
2. 左侧按需勾选「导出桶和文件」，点击 **导出平台 ZIP**
3. 在目标实例同一菜单项上传该 ZIP（仍兼容旧版单 `.json`）
4. 等待自动预览；确认无误后选择冲突策略并执行导入

### 1.3 导入策略

| 策略 | 含义 |
|------|------|
| 覆盖更新（默认） | 同业务键按文件内容覆盖 |
| 跳过已存在 | 目标已有记录保持不变 |
| 有冲突即中止 | 预检发现冲突则整包不写 |

误传业务应用导出文件会被拒绝。各节失败互不影响。

## 2. 应用数据包

按 **单个业务应用** 迁移配置、模型与可选行数据。内置系统应用 `EADAF` **不可导出、不可导入**（平台能力请用第 1 节）。

### 2.1 导出内容（概要）

- 应用配置（SSO / API 接入、数据域 Scope、顶层 Skill 说明）
- 数据实体结构（实体 / 字段 / 枚举 / 关系 / Scope 文档）
- 数据库连接元数据（不含密码；导入时优先匹配目标连接，失败则用目标同类型凭证创建本地连接）
- 物化库表摘要；实体绑定的逻辑元数据（数据标准目录不随包带走，仅带 code+version 供重映射）
- 实体行数据（仅 PostgreSQL / MySQL 物化表，保留原主键；受数据模式控制）
- API 服务、采集管道、Outbound Webhook、指标与卡片、命中本应用的钩子
- 该应用专用 Skill / Tools / AI Scope（不含全局 / 平台 Skill）
- 可选：UAC（用户 / 部门 / 授权）；可选：该应用相关存储对象文件

### 2.2 导出选项

| 选项 | 说明 |
|------|------|
| 结构和数据（默认） | 实体结构与行数据一起导出 |
| 仅数据 | 仍带结构指纹供校验；导入时不落结构，目标无同 code 实体或版本不符则跳过写数 |
| 携带 UAC | 含用户 / 部门 / 授权；不勾选则仅含被引用的角色与权限 |
| 携带存储文件 | 该应用桶内对象 + 归属本应用的对象；不勾选仅桶元数据 |
| 安全模式标记 | 写入包内供预览；导入侧默认仍开启安全模式（已发布资源可退回 draft），可在导入侧关闭以保持源发布状态 |

### 2.3 操作步骤

1. 打开 **应用部署 → 应用数据导出/导入**
2. 左侧选择应用与选项，点击 **导出 ZIP 文件**
3. 在目标实例同一菜单项上传该 ZIP（勿传到「EADAF数据导出/导入」）
4. 等待自动预览（含连接匹配结果）；选择冲突策略后确认导入

### 2.4 导入说明

- 冲突策略与平台包相同：覆盖 / 跳过 / 中止
- 同 code 的软删应用会在导入时被物理清除后继续（避免 tombstone 阻断）
- 导入不可自动撤销；请先在目标环境备份或在空/可丢弃实例上验证
- 平台包与应用包互斥入口：传错类型会被拒绝或提示换页

## 3. 与运行时安装包的区别

| | 应用部署数据包 | `pnpm pack:*` 运行时包 |
|--|----------------|------------------------|
| 产出位置 | 浏览器下载 ZIP | `deploy-artifacts/EADAF/`、`deploy-artifacts/APP/` 的 `.tar.gz` |
| 用途 | 实例间迁配置 / 业务数据 | 装 Docker/K8s、换程序镜像、跑 SQL |
| 是否含容器镜像 | 否 | 是（平台安装/升级等） |
| 操作面 | 已运行的管理端 | 开发机打包 + 目标机 `start.sh` / `apply.sh` |

现场装环境、换版本请用运行时包；两套环境之间同步模型与平台能力请用「应用部署」里的数据包。
